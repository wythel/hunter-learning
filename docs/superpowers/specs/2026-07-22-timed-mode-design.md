# 限時模式（10 秒答題）設計文件

日期：2026-07-22
狀態：已由使用者核准

## 目標

為五個遊戲加上「限時模式」難度選擇：**算數大戰、連鎖算數、湊十大師、奇偶偵探、音符星球**。
限時模式下每個作答單位限時 10 秒，逾時視同答錯：播錯誤音效、顯示正確答案、自動進下一題。

## 設定頁 UI

每個遊戲的 `Settings.jsx` 新增一列設定「限時模式」，透過現有 `SettingsPage` 的 settings 陣列：

| value | icon | text | sub |
|-------|------|------|-----|
| `false`（預設） | 😌 | 悠閒模式 | 不限時 |
| `true` | ⏱️ | 限時挑戰 | 10 秒 |

選擇結果以 `timed`（boolean）放進 `navigate(..., { state })` 傳給 Game。

**例外**：湊十大師選了「配對模式」時，隱藏「限時模式」這列（配對模式不支援限時）；若使用者先選限時再切到配對模式，開始遊戲時強制視為不限時。

## 共用元件

### `src/hooks/useCountdown.js`（新增）

- 輸入：`{ seconds, enabled, paused, resetKey, onExpire }`
- 內部用 100ms tick（進度條平滑），以 deadline 時間戳計算剩餘，避免 tick 漂移
- 回傳：`{ fraction /* 1 → 0 */, timeLeft /* 秒，向上取整 */ }`
- `enabled=false` 時完全不跑（悠閒模式零成本）
- `paused=true` 時凍結剩餘時間（顯示答案動畫期間）
- `resetKey` 改變時重置為滿的 10 秒
- 到 0 時呼叫一次 `onExpire`（每個 resetKey 週期只觸發一次）

### `src/components/TimeBar.jsx`（新增）

- 顯示一條會縮短的水平進度條，接收 `fraction`（1 → 0）
- 顏色：正常為主題 teal；剩餘 ≤ 3 秒（fraction ≤ 0.3）轉紅色並加閃爍動畫
- 悠閒模式下不渲染（由各 Game 判斷 `timed` 決定是否放置）

## 各遊戲行為

所有遊戲：`useGame` 新增 `timed` 參數；新增 `handleTimeout`，行為比照答錯（`stats.wrong + 1`、`sound.wrong()`），並額外顯示正確答案約 1 秒後自動進入下一個作答單位。動畫/回饋期間計時器暫停（`paused`），新作答單位開始時以 `resetKey` 重置。

| 遊戲 | 作答單位 | 逾時後顯示的正確答案 | 其他效果 |
|------|----------|----------------------|----------|
| 算數大戰 | 每題 | 顯示「正確答案：N」 | 怪物攻擊、扣玩家 HP（可能觸發 game over） |
| 連鎖算數 | 每題 | 顯示「正確答案：N」 | 同上（沿用該遊戲既有答錯流程） |
| 湊十大師（選答案模式） | 每題 | 高亮正確選項 | — |
| 湊十大師（配對模式） | 不適用 | — | 不支援限時 |
| 奇偶偵探（模式 1） | 每題 | 高亮正確按鈕（奇數/偶數） | — |
| 奇偶偵探（模式 2 分類） | 每題 | 高亮所有應選的卡片（比照現有答錯回饋） | 逾時視同送出且答錯 |
| 音符星球 | **每個音符**（3 音符模式下各 10 秒） | 比照現有答錯回饋顯示正確音名/琴鍵 | 該音符標記為 wrong，跳下一個音符 |

逾時輸入處理：逾時當下鎖定輸入（沿用各遊戲 `locked` ref），避免逾時與手動作答同時觸發（race condition：`onExpire` 先檢查 `locked.current`）。

## 不變的部分

- 結算畫面、星星計算（`calculateStars`）不變 — 逾時就是多一次 wrong
- 悠閒模式（預設）行為與現在完全相同
- 未列入的遊戲（學看時鐘、英文配對、記憶翻牌、打地鼠、對稱遊戲）不變

## 測試

- `useCountdown`：enabled/paused/resetKey/onExpire 行為（fake timers）
- 各遊戲 `useGame`：`timed=true` 時逾時 → wrong +1、進下一題；`timed=false` 時無計時
- 湊十大師：配對模式下無計時
- 既有測試全數維持通過
